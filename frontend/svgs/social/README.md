# Ícones sociais

SVGs de Instagram e Telegram provenientes de [Simple Icons](https://github.com/simple-icons/simple-icons),
distribuídos sob [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).

O rodapé incorpora estes mesmos desenhos como SVG no HTML, usando `currentColor`
para acompanhar a cor dos controles e o hover. Os arquivos originais ficam aqui
como referência. Os nomes acessíveis e os destinos ficam nos links HTML; os
desenhos são decorativos para leitores de tela.
