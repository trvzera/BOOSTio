# Ícones sociais

SVGs de Instagram e Telegram provenientes de [Simple Icons](https://github.com/simple-icons/simple-icons),
distribuídos sob [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).

O rodapé usa os arquivos como máscaras CSS para acompanhar a cor dos controles
e o hover. Os nomes acessíveis e os destinos ficam nos links HTML; os desenhos
são decorativos para leitores de tela.
